# King Estética — cuidados para motos

Site da King Estética, especializado em limpeza e cuidado de motos.

## Serviços

- Limpeza simples: a partir de R$ 20,00
- Limpeza de manutenção: a partir de R$ 50,00
- Limpeza detalhada: a partir de R$ 89,90

Os valores podem variar conforme o modelo e as condições da moto. O atendimento é aos sábados e domingos, das 12h às 18h. A busca e a entrega são combinadas no agendamento.

## Arquivos do site

- `index.html`: página inicial e arquivo principal para publicação.
- `King Estética Automotiva.html`: cópia da página com o nome original do projeto.
- `assets/`: imagens usadas no site.
- `vercel.json`: configuração para publicação na Vercel.

## Publicar na Vercel

1. Envie este repositório para o GitHub.
2. Na Vercel, escolha **Adicionar novo projeto** e importe o repositório.
3. Mantenha a configuração como site estático; não é necessário escolher uma estrutura de programação.
4. Clique em **Publicar**. A Vercel fornecerá um endereço gratuito terminado em `vercel.app`.

Um domínio próprio, como `kingestetica.com`, precisa ser registrado separadamente e conectado ao projeto na Vercel.

## Abrir localmente

Abra `index.html` no navegador para visualizar o site.
